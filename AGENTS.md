# Nivaran, agent guide

Grievance-preparation prototype for Build What Moves India. One synthetic journey: a rejected PF transfer. Working plan, shot list and status: `docs/demo-build-plan.md`. Engineering constraints that outlive the video: `docs/voice-prototype-build-plan.md`. Field research on the real CPGRAMS portal: `docs/cpgrams-research.md`.

## Layout

- Root: Next.js 15 app. Legacy web demo (`/file`, `/dashboard`, `/admin`), research prototype (`/prototype`, `/study`), and three API routes the mobile app calls: `app/api/live-token` (Gemini Live ephemeral token), `app/api/chat` (typed chat through `generateContent` with the same `propose_facts` tool; the app validates every proposal), and `app/api/extract` (reads the two sample documents). All three require the `x-nivaran-demo-key` header and allow only localhost browser origins through `app/api/cors.mjs`; the deployed site is same-origin. `public/app/` holds the committed Expo web export, served at `/app` by the rewrites in `next.config.mjs`.
- `mobile/`: Expo SDK 57 app, one codebase for Android and web. Routes in `mobile/app/` (`index` Home, `chats`, `profile`, `new`, `case/[id]` with four tabs). The three top-level screens share `src/ui/BottomBar.tsx`, a plain component that switches routes with `router.replace`; there is no tab navigator. Screens in `mobile/src/screens/`. Case rules in `mobile/src/core/`, imported only through `mobile/src/core/index.ts`; its `README.md` is the contract.
- Ownership: Codex owns `mobile/src/core/**`, its tests, `mobile/assets/fixtures/` and `app/api/extract/`. Claude Code owns everything else under `mobile/` plus `app/api/live-token/`. Change the other side's folder only by agreement.

## Commands the environment does not advertise

- Root tests: `node --test tests/*.test.mjs`. Mobile core and route tests: `cd mobile && npm test` (runs through tsx, so Node 20 works).
- Any `expo` command needs Node 22.13 or newer; the Android build also needs JDK 17 on `JAVA_HOME`. `mobile/package.json` has `web`, `android`, `export:web`, `typecheck`.
- Phone over USB: `adb reverse tcp:8081 tcp:8081` and `adb reverse tcp:3100 tcp:3100` after every reconnect, then `npm run android` in `mobile/` and the API server at the root. `mobile/.env` points `EXPO_PUBLIC_API_BASE` at port 3100 for both the phone and the web dev build, and bakes the demo code in through `EXPO_PUBLIC_DEMO_KEY`; Expo reads `.env` only at start, so restart Metro after editing it. Port 3000 on this PC is often taken by another project. Two Next servers on one checkout fight over `.next/trace` and the second one dies with EPERM; give the second its own build directory: `NIVARAN_NEXT_DIST_DIR=.next-mobile npx next dev -p 3100`.
- Expo Go works for everything except gapless voice playback; `src/voice/audio.native.ts` falls back to one WAV per reply when the playback module is missing. Start with `npx expo start` (no `--dev-client`) and open `exp://127.0.0.1:8081` on the phone via `adb shell am start -a android.intent.action.VIEW -d exp://127.0.0.1:8081`.
- Native Android builds on this PC must use the SDK through the junction `C:\AndroidSdk` (`sdk.dir` in `mobile/android/local.properties`). The real SDK path contains a space, which makes CMake invoke the compiler as `CLANG_~1` and every C++ link fails with missing libc++ symbols. Delete the `.cxx` folders after changing the SDK path.
- Web export: `cd mobile && npm run export:web` writes `public/app/`; commit it, then deploy the root with Vercel. Environment keys are listed in `.env.example`. A running `next start` keeps its list of `public/` files from startup, so restart it after every export or the new bundle path falls through to `index.html` and the app never mounts.

## Rules that are not visible from the code

- Core functions are immutable and throw on bad explicit input; `applyProposals` reports bad model input in `rejected` instead of throwing. Always keep the returned case. A proposal is never a confirmation: the citizen taps Confirm, and a spoken "yes" confirms nothing.
- The draft text comes only from confirmed facts. An unknown or conflicting exit date renders the verification sentence, never a picked date.
- Every user-facing string goes through `t()` from `mobile/src/i18n.tsx`. English text is the key; add the Hinglish line to the `HI` map in the same file. Core question wording comes from `textHi`/`textEn` chosen by the app language, and the app language overrides a case's stored language.
- Platform splits use `name.native.ts` and `name.web.ts` next to a `name.d.ts` contract (audio, store, files, settings). Keep `tsconfig.json` free of `moduleSuffixes`; it breaks third-party types. TypeScript stays on 5.9, the version Expo supports.
- Typed chat goes through the model by default and falls back to the scripted PF questions when the server, key or model is unavailable, or when Profile sets "Scripted questions" (setting `aiChat=off`; the web QA scripts set it to keep runs deterministic). The free tier on this key allows 20 `generateContent` requests per day per model (`GenerateRequestsPerDayPerProjectPerModel-FreeTier`), so the chat route walks `CHAT_MODEL` then the comma-separated `CHAT_FALLBACK_MODEL` list on 429, 503, 404 or a 12 s timeout, then repeats the chain on `GEMINI_API_KEY_BACKUP` if set. Automated tests must keep `aiChat=off` so they never spend that quota; run a model chat by hand at most a few times a day.
- Voice is push to talk with automatic activity detection off. The API key lives only on the server; the app fetches a one-use token with the demo code the person types in once. Gemini free tier terms forbid personal data, so every demo uses the fixture story and the two sample documents.
- The two sample PNGs are matched by SHA-256 in `mobile/src/core/fixtures/extractions.json`. Regenerate both with `node mobile/src/core/fixtures/render.mjs` whenever the HTML changes, or `extract.test.ts` fails.
- Save status flips to Saved only after the store write resolves. Web storage keeps one JSON document per case in `localStorage`; the phone keeps the same JSON in one SQLite table. There is no sync between devices.
