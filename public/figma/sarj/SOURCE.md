# Hero assets

Exported from the user-provided [Sarj hero in Figma](https://www.figma.com/design/rlV4N3WTpLd39K9nAP9rm7/Sarj---Website?node-id=363-2336).

Downloaded via Figma design context on 2026-09-08 for the Nivaran homepage adaptation.

- `landscape-base.png`: background base photograph
- `landscape.png`: blue sky and green landscape
- `texture.png`: landscape texture overlay
- `orb.png`: assistant orb artwork
- `send.svg`: composer arrow
- `sparkles.svg`: decorative sparkle
- `arrow.svg`: CTA chevron

Original exports are kept locally so the page does not depend on expiring Figma asset URLs. The copy, interactions and responsive layout are adapted for Nivaran. The reference's proprietary typeface is replaced with the system Georgia serif.
